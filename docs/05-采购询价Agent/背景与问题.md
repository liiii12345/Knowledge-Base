# 05 · 背景与问题

## 一句话

采购人员问的是人话（「山东省东鹏抛釉砖近半年什么价」），价格库认的是规范字段（分类 / 供应商全称 / 规格 / 品牌 / 地区 / 日期）。**中间那道翻译层，怎么做才不会查空？**

## 场景

- 提问是口语的：说简称、说俗称、说错别字，还经常只提其中一两个维度
- 价格库是规范的：字段值固定，匹配不上就是 0 条
- 单次查询可能回上千条，聊天窗口既塞不下也不该塞
- 查询是高频动作，一天几十次，每次多调一次接口成本就翻倍

## 为什么值得做

需求原文只有一句「AI 自动辨别价格库内的采购价格，进行价格分析」，看着是个检索功能。真正难的是另一件事：**Agent 太勤快**。它倾向于把每个维度都填满——用户没提供应商，它也要猜一个塞进去。实测下来，不做约束的方案**空结果率 97.5%**，几乎每次都查了个寂寞。

这个案例要讲清的是：一句口语提问到一次正确查询之间，哪些约束必须硬做，以及**约束怎么验收**。
