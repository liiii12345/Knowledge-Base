# 日报规格说明（11 板块）

本文件是日报的**对外规格**，任何改动都要先改这里再改代码。

## 板块定义

| # | 板块 | 内容要求 | 空数据处理 |
|---|---|---|---|
| 0 | 核心动态 | 3-5 行纯事实，格式「来源：发生了什么」 | 写"今日无通过质量红线的新内容" |
| 1 | 今日速览 | 3-5 条，带热度 🔥/🔥🔥/🔥🔥🔥 | 同上 |
| 2 | 今日金句 | 一句话原文 + 出处 + 链接 | 写"今日无符合标准的金句条目" |
| 3 | 信息分层 | ⚡必看 3 条 / 📖速读 5-10 条 / 🔬深读 2-3 条 | 每档写"本档无内容" |
| 4 | YouTube 播客更新 | 表格：频道\|主题\|嘉宾\|核心内容\|时长\|链接 | 写"今日无播客更新" |
| 5 | Twitter/X 精选 | 按主题分组 | 写"今日无推文入选" |
| 6 | 趋势与关联 | 仅 ≥2 个来源的共同话题 | 写"今日无明显跨来源共同话题" |
| 7 | 行动建议 | ≤3 条，可执行 | 写"今日无需立即执行的动作" |
| 8 | 待观察 | 单一来源、待交叉验证 | 写"暂无" |
| 9 | 数据看板 | 今日 vs 昨日，百分比 | 写"无昨日数据"，**禁止编造** |
| 10 | 推荐阅读 | ≤3 条，优先深读档 | — |
| 附录 | 质量红线拦截 | 被丢弃条目的标题 + 红线编号 | 写"今日全部条目通过" |

**板块顺序固定，缺失时写占位语，不允许省略板块**——订阅者靠固定位置快速定位信息。

## 五条质量红线

| 编号 | 红线 | 判定 | 实现位置 |
|---|---|---|---|
| R1 | 中文摘要 | 推文 30-80 汉字；YouTube ≥20 汉字 | `analysis/quality_gate.py` |
| R2 | 来源标注 | author / handle / channel 至少一个 | 同上 |
| R3 | 可点击链接 | 必须 http(s) 开头 | 同上 |
| R4 | 无主观推断 | 禁用：这意味着、预示着、标志着、我们有理由相信、毫无疑问、必将 | 同上 |
| R5 | YouTube 三要素 | 主题 + 嘉宾 + 核心内容 | 同上 |

> 红线是**代码关卡**，不是 prompt 里的请求。模型违反时条目被挡在正文之外，
> 并在附录里列出违反原因。理由是：要求模型遵守 ≠ 模型一定会遵守。

## 热度计算规则

禁止凭感觉打星。热度 = 新鲜度 + 关键信号：

| 信号 | 分值 |
|---|---|
| 6 小时内 | +2 |
| 12 小时内 | +1 |
| 含关键词（发布/开源/漏洞/定价/上线/限制/封禁/下线/降价/收购） | 每个 +1，上限 +2 |

合计 ≥3 → 🔥🔥🔥；2 → 🔥🔥；否则 🔥。

## 写作规范

1. **事实与判断分离**：摘要只写发生了什么，行动建议才允许判断
2. **量化优先**："冷启动 180ms → 40ms"，不用"大幅提升"
3. **不确定就标注**：无法确认的标「待核实」
4. **不许硬凑**：没有就写"今日无 XX"
5. **链接原样保留**：不改写、不缩短、不丢弃
