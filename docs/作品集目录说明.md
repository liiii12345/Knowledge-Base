# 作品集目录说明

每个作品放一个子文件夹，用编号开头。每个作品内放 **3 个文件**，这是面试官最想看的最小完整单元：

1. `背景与问题.md` — 什么场景、什么问题、为什么值得做（300 字内讲清）
2. `我的思考过程.md` — 你怎么拆解、筛选、取舍、验证（这才是你的能力证明）
3. `产出与复盘.md` — 做了什么、量化结果、踩了什么坑、如果重来改哪里

铁律：
- **脱敏**：公司名、业务数据、内部截图一律不出现，涉及真实场景全部改写为通用表述或虚构数据。
- **诚实**：分清"我做的"和"我参与的"；不要用"主导、拍板"这类词。
- **可视化**：多用表格、流程图、状态机表达，一图胜千言。
